# API Application Boundary

Phase 1 NestJS domain API on host port `43171`.

Owns sessions, authorization, Zod validation, lifecycle rules, transactional history, immutable artifact references, exports, and health endpoints. Start from the root README. The manual CRM is the first feature module; future resume and source modules are added as complete vertical increments. See `src/domain.ts`, `src/crm.service.ts`, `src/crm.controller.ts`, and the Prisma schema/migrations.
