# PDF Font Assets

Noto Sans Regular and Bold are bundled for deterministic offline PDF export, including English, Russian and Ukrainian text. The static TrueType files come from [notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans).
